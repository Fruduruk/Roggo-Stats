# Version 0.7.0

## Agent
- Improved the reliability of match data collection, especially when receiving fragmented or multiple events at once
- Matches now store the Rocket League playlist they were played in
- Failed match saves now automatically create a debug dump to help diagnose data collection issues
- The WebUI will now only open automatically after Rocket League closes if at least one match was successfully saved
- Improved handling of Rocket League events and raw API data

## WebUI
- Updated compatibility for Agent version 0.7.0
- Updated local communication with the Roggo Stats Agent
