# Version 0.8.0


## Highlights

- Completely redesigned Day and Session views
- Added automatic session grouping by playlist and time between matches
- Added interactive session timelines, match selection and detailed session analysis
- Added beeswarm plots and filters for comparing player statistics across matches
- Introduced the shared `roggo_contract` crate used by both Agent and WebUI
- Significantly restructured Agent, database and WebUI code for clearer separation of responsibilities

## Agent

- Added new Day, Session and Session Details APIs
- Added support for retrieving previously played days
- Sessions are grouped by playlist and a maximum one-hour pause between matches
- Sessions distinguish between consistent teams and solo/changing-team sessions
- Session data now includes scores, playlists, teammates, opponents, MVP status, advanced statistics and statfeed events
- Added batched loading of matches, teams, players and statistics for session analysis
- Improved date handling with the 04:00 day boundary used by the Day view
- Improved packet import/capture logging and added initial Boost Pickup event handling

## WebUI

- Added a new Day page with date navigation, session cards and daily statistics
- Day statistics now include matches, record, winrate, playtime, session count and longest session
- Added a redesigned Session page with:
  - Interactive match timeline
  - Selectable match cards with score, result and MVP/ACE status
  - Analysis and Details views
  - Match arena, time, duration and opponent information
  - Tracker Network links for players
- Added beeswarm plots for core and advanced player statistics
- Added Win/Loss, MVP and Time filters for session analysis
- Added enemy averages and team score-difference analysis
- Selected or hovered matches are highlighted across the analysis views
- Redesigned typography, panels, controls, header, footer and theme handling
- Improved dark and light mode support
- Updated compatibility for Agent version 0.8.0
